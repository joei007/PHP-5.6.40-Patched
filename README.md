# Patch อย่างง่ายสำหรับ CVE-2026-109618 และ CVE-2026-109619 ครับ

## CVE-2026-109618
Patch ตัวนี้จะเปลี่ยนจาก longjmp ไปเป็น _exit เลย เพื่อกันไม่ให้ระบบ Shutdown กลับไปอ่านข้อมูลในโครงสร้างที่ยังสร้างไม่เสร็จเพราะหน่วยความจำเต็มไปก่อน ซึ่งป้องกันปัญหาได้ แต่จะเกิดปัญหาใหม่คือ PHP จะข้าม Shutdown function ที่ลงทะเบียนไว้ทั้งหมดและจบการทำงานเลย สำหรับผู้ที่ใช้ PHP-FPM ตัว Master Process จะ Fork Child ใหม่มาแทนตัวที่ปิดไปครับ

## CVE-2026-109619
Patch ตัวนี้จะ Clear ค่าที่เกี่ยวกับ Session ที่ไม่ได้ Clear ก่อนเริ่ม Process ใหม่ ซึ่งมันกันในส่วนของผมได้ แต่ถ้าส่วนของคุณมี Mod อะไรที่จะต้อง Clear ค่าก่อนจบ Process หรือมีการใช้ PHP_VALUE หรือ PHP_ADMIN_VALUE หรือ มีการใช้ Web Socket ในการเชื่อมต่อ PHP-FPM แทน Unix Socket ก็อาจจะยังมีความเสี่ยงอยู่
